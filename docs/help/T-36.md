# T-36 — السلة

## المطلوب (المنفَّذ)

- زر **«حذف»** بنص ظاهر بجانب كل صنف (أيقونة + كلمة «حذف»)، وليس أيقونة فقط.
- زر **«إفراغ السلة»** فوق الجدول، يفتح تأكيدًا قبل الحذف الكامل.
- تعديل الكمية بزرَّي **+** و**−** (موجود، مع احترام الحد الأدنى للطلب والمتاح من المخزون).
- خيار **«تراجع»** لبضع ثوانٍ (٦ ثوانٍ) بعد حذف صنف: يختفي الصنف فورًا من القائمة والإجماليات، ولا يُحذف على الخادم فعليًا إلا بعد انقضاء المهلة؛ فالتراجع لا يرسل شيئًا ويُبقي تثبيت السعر سليمًا.

## أين طُبِّق

- الواجهة: `web/src/pages/commerce/CartPage.tsx` (الحذف المؤجل + شريط التراجع + تأكيد الإفراغ).
- الخادم: `DELETE /commerce/cart/items` عبر `cart.clear_cart` يُفرغ السلة ويحرّر كل أقفال الأسعار.

## شرح

«يمكنك حذف أي صنف أو تعديل كميته قبل تأكيد الطلب.»

## المساعد

«العميل مش عارف يمسح صنف» ← زر «حذف» بنص ظاهر بجانب الصنف في السلة، مع «تراجع» لثوانٍ بعد الحذف.
