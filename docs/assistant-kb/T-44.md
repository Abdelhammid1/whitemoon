# معرفة المساعد — T-44: تأكيد بخطوة واحدة وتتبّع الطلب

## العميل مش عارف طلبه وصل لفين؟
صفحة الطلب فيها شريط التقدّم (تم الطلب ← مؤكد ← جاري التجهيز ← في الطريق ← تم التسليم) وتتبّع الشحنة، ويصل العميل إشعار عند كل مرحلة.

## كم خطوة لتأكيد الطلب؟
نقرتان بعد السلة: «طلب آجل/نقدي» لفتح ملخص التأكيد (الأصناف والمبلغ والرسوم وموعد التوصيل)، ثم «تأكيد». 

## متى تصل الإشعارات؟
عند كل تغيّر مرحلة: تأكيد الطلب، بدء التجهيز، خروجه في الطريق، وتسليمه. والإلغاء يُشعَر أيضًا.
